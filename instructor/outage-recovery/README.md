# Outage Recovery Fixture

`provider-timeout.sample.json` is an instructor-created training fixture, not an
actual provider transcript or live run. It demonstrates how to classify an API
timeout without treating the missing attack result as proof of a defense. Do not
label it as fresh live evidence. No credentials or customer records are included.

If the classroom provider is unavailable, use this file to discuss evidence
quality, then let participants continue with the deterministic tool-level tests,
source repair, and local replay once service returns. A fixture cannot replace a
live before/after verification claim.
